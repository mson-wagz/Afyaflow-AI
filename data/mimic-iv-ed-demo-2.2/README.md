# MIMIC-IV-ED Demo v2.2 source files

Unmodified public demo files from [PhysioNet](https://physionet.org/content/mimic-iv-ed-demo/2.2/).
The bundled ED tables contain 222 stays from 64 distinct source patients.
These are de-identified historical hospital records, not synthetic observations
or current admissions. No credential-restricted MIMIC files are included.
